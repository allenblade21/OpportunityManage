# 机汇 OpportunityManage · 商机管理系统

一个面向个人销售 / 小型销售团队的轻量商机管理工具(Web 版):以**商机**为中心,把**联系人、跟进项、想法**有序地组织起来,统一的 P0–P3 优先级贯穿全局,保证每个商机永远有"下一步"。

> 当前为 **v0.1 MVP**:设计文档齐备,应用已完成初步开发(本地单机版,数据存于浏览器 localStorage)。

## 运行应用(MVP)

```bash
npm install
npm run dev       # 开发模式,默认 http://localhost:5173
npm run build     # 类型检查 + 生产构建(输出 dist/)
npm run preview   # 预览生产构建
npm test          # Vitest 单元测试(store 联动规则 + 工具函数)
npm run e2e       # E2E 冒烟测试(需先 build;自起 preview + Chromium 走核心路径)
```

**已实现:**

- 四对象(商机/联系人/跟进项/想法)完整 CRUD:全局快速新建、编辑、删除(级联清理关联数据)
- 商机:**看板拖拽变更阶段** / 列表视图与筛选、详情页阶段步进条、赢单确认、输单必填原因、阶段变更自动写时间线并更新默认赢率
- 跟进闭环:完成时**填写跟进结果**(写入时间线)+ 默认勾选「立即创建下一次跟进」;自动刷新联系人最近联系时间;载入时逾期提醒、顶栏逾期角标、工作台「无下一步」商机警示
- 想法:速记输入、转为跟进项 / 升级为商机(双向链接)、搁置与重新激活
- **全局搜索(⌘K / Ctrl+K)**:跨四对象搜索,回车直达
- **跟进日历视图**:月历按截止日展示(优先级配色、逾期红条、完成划线),点击条目编辑,悬停日格「+」快建当日跟进
- **浏览器到期通知**:顶栏铃铛开启,跟进截止前 15 分钟(或已逾期)弹桌面通知,每条一次,点通知回到跟进页
- **数据导入导出(设置弹窗)**:Excel 四工作表导出,修改后可再导入(按 ID 更新、无 ID 新增);JSON 无损备份与整体恢复
- 工作台实时聚合(KPI、加权在途金额、阶段漏斗、今日/逾期跟进、高优先级商机、最近动态)
- 深色模式、响应式、localStorage 持久化(内置演示数据,设置中可重置)

**测试:** 43 个单元测试覆盖阶段流转/闭环联动/想法转化/级联删除/Excel 与 JSON 往返/通知判定/日历网格等业务规则;`scripts/e2e.mjs` 覆盖拖拽、搜索、编辑、闭环、输单、日历、通知(桩)、导出下载与导入回灌等 24 项端到端断言。

**规划中(见 [迭代路线](docs/design.md#9-迭代路线)):** 自定义阶段与标签、统计报表、多用户后端(Node + Prisma + SQLite)。

## 核心设计一览

- **四个核心对象:** 商机(阶段推进)· 联系人(角色分类)· 跟进项(时间分组 + 闭环)· 想法(可转化为跟进/商机)
- **统一优先级:** P0 紧急(红)/ P1 重要(橙)/ P2 普通(蓝)/ P3 观察(灰),全局排序过滤
- **阶段流:** 线索 → 初步接触 → 需求确认 → 方案报价 → 谈判 → 赢单/输单,色带由浅至深表达"离成交越近"
- **跟进闭环:** 完成跟进 → 填写结果 → 引导创建下一次跟进,杜绝商机被"晾着"

详细内容见 [设计方案文档](docs/design.md)。
