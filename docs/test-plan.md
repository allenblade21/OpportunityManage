# 测试方案与用例(V0.5)

> 覆盖功能用例与边界/异常用例,每条标注自动化落点。当前:**单元测试 86 个、E2E 断言 43 项,全部通过**。

## 1. 测试策略与运行方式

| 层级 | 工具 | 覆盖目标 | 运行 |
| --- | --- | --- | --- |
| 单元测试 | Vitest(node 环境 + fake-indexeddb) | store 业务规则与联动、工具函数、Excel/JSON 序列化、通知判定、存储适配器 | `npm test` |
| 端到端 | Playwright(Chromium)+ 自起 vite preview | 真实浏览器用户路径:渲染、拖拽、弹窗、下载、导入、迁移、移动端 | `npm run build && npm run e2e` |
| 手动检查 | — | 自动化难以覆盖的环境项(见 §4) | 发布前走查 |

测试文件:`src/__tests__/*.test.ts`(单元)、`scripts/e2e.mjs`(E2E,截图输出至 `e2e-artifacts/`)。

## 4. 手动检查项与已知限制

**发布前手动走查:** 真机浏览器通知(headless 无法验证系统级弹窗)、隐私/无痕模式降级、⌘K 在 macOS 真机、多标签页同开(最后写入者胜,暂不做跨标签同步)、约 5 千条数据量下的滚动性能。

**已知限制:** 单机单用户(多标签页不同步);IndexedDB 按“浏览器+域名”隔离,换环境需用 JSON 备份迁移;Excel 导入不校验跨对象引用完整性(如商机 ID 不存在的跟进会成为“无关联”跟进)。
