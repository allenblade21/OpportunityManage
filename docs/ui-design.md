# UI 设计规范

> 视觉基准:高保真原型 [`prototype/index.html`](../prototype/index.html)(design source of truth)。本文档将原型中的设计决策沉淀为可执行的规范,供开发实现与后续迭代遵循。

---

## 1. 设计原则

1. **信息密度优先** —— 这是高频操作的业务工具,不是营销页:字号基准 14px、留白克制、一屏尽量多信息但层级清晰;
2. **状态一眼可见** —— 优先级(色底胶囊)、阶段(色带/色点)、逾期(整条标红)必须不阅读文字即可识别;
3. **录入零阻力** —— 全局「快速新建」、想法页常驻速记输入框;表单只留必填 + 常用字段;
4. **色彩即语义** —— 品牌绿只用于主操作与激活态;红橙蓝灰固定映射 P0–P3;绿色深浅固定映射阶段进度,不做装饰性用色。

## 2. 布局系统

```
┌─────────┬──────────────────────────────────┐
│         │  顶栏 56px:全局搜索 + 快速新建     │
│ 侧边导航  ├──────────────────────────────────┤
│ 224px   │  内容区 padding 22/24px           │
│ 深绿底   │  栅格间距统一 14px                 │
└─────────┴──────────────────────────────────┘
```

- 侧边导航:深绿底(品牌锚点),含 logo、五个模块入口(带数量角标)、设置与用户区;
- 内容区每页结构:`phead 页头(标题 + 统计 + 筛选/操作)` → 页面主体;
- 双栏栅格:工作台 `1.55fr : 1fr` 与 `1fr : 1fr`;商机详情 `1.5fr : 1fr`。

## 3. 色彩令牌(Design Tokens)

实现方式:CSS Custom Properties 定义于 `:root`,深色以 `@media (prefers-color-scheme: dark)` 重定义,并用 `:root[data-theme="dark"] / [data-theme="light"]` 支持手动切换覆盖。

## 4. 字体与排版

| 用途 | 字体栈 |
| --- | --- |
| 界面文字 | `-apple-system, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif` |
| 数字/金额/日期 | `ui-monospace, "SF Mono", "Cascadia Mono", Menlo, Consolas, monospace` + `font-variant-numeric: tabular-nums`(类名 `.num`) |

**字号阶梯:** 11(角标)/ 12(辅助)/ 12.5–13(次级)/ **14(正文基准)**/ 14.5–16(卡片标题)/ 20–21(页面标题)/ 26(KPI 数字)。行高 1.6;金额一律等宽呈现(台账感)。

**其他:** 圆角 10px(卡片)/ 8px(按钮、输入框)/ 99px(胶囊);阴影两层低透明度 `0 1px 2px + 0 4px 14px`;栅格间距 14px。

## 5. 组件规范

| 组件 | 规格与状态 |
| --- | --- |
| **主按钮** `.btn-pri` | 品牌绿底白字,hover 加深;每个视图至多一个主按钮 |
| **次按钮** `.btn` | 白底描边;`btn-sm` 用于面板内操作 |
| **优先级胶囊** `.chip .p0–.p3` | 色底 + 同色深文字;列表页用全称「P0 紧急」,卡片内用短形式「P0」 |
| **状态胶囊** | 赢单/已采纳 `c-ok`;待评估/把关者 `c-warn`;已搁置 `c-hold`;主要联系人 `c-brand` |
| **阶段点** `.st + .dot.bg-sN` | 色点 8px + 阶段名;看板列头、列表行、工作台商机行共用 |
| **看板卡片** `.kcard` | 客户名(小灰)→ 商机名(600)→ 金额(等宽绿)+ 赢率 → 底部:优先级 + 下次跟进 + 联系人头像;hover 描边变品牌色;无下一步跟进时显示橙色「无跟进」警示 |
| **跟进条目** `.fu` | 复选框 + 类型徽标 + 标题 + 关联对象(灰)+ 优先级 + 截止时间;逾期时整条时间红色加粗;完成态删除线 |
| **复选框** `.check` | 17px 圆角方框,完成后品牌绿底白勾 |
| **时间线** `.tl` | 左竖线 + 节点;关键节点(阶段变更/赢单)品牌色描边 |
| **阶段步进条** `.stepper` | 详情页顶部;已过阶段实心 s3 色、当前阶段空心 s5 描边加粗文字、未来灰;点击即推进阶段 |
| **KPI 卡** `.kpi` | 标签(12.5 灰)→ 数字(26 等宽 700)→ 补充说明(12);增长绿/风险红 |
| **表格** | 表头 12px 灰、行高约 44px、hover 变 paper 色、整行可点击 |
| **弹窗** `.modal` | 640px 居中,双列表单栅格;必填以红色 `*` 标注;Esc / 点击遮罩 / 取消关闭 |
| **Toast** | 底部居中,反色底,2.6s 自动消失;可带一个操作按钮(如「创建下一次跟进」) |
| **头像** `.av` | 圆形,姓氏首字,brand-soft 底 |
| **看板拖拽** | 卡片 `draggable`,拖起时半透明;目标列品牌色虚线描边 + soft 底;落下即变更阶段(赢单需确认) |

## 6. 页面规格

### 6.1 工作台
KPI ×4(进行中商机 / 在途总金额 + 加权 / 本周待跟进 + 逾期 / 本季赢单率)→ 商机漏斗(按阶段金额,色带 s1–s5)+ 今日跟进(逾期置顶,可直接勾选完成)→ 高优先级商机(P0/P1,含下次跟进与「无下一步」警示)+ 最近动态(全局时间线前 6 条)。

### 6.2 商机(看板 / 列表)
页头:统计 + 看板/列表切换 + 阶段/优先级筛选 + 排序 + 新建商机。看板 6 列(线索→赢单),列头含数量与金额小计;列表含全部字段列。卡片/行点击进入详情。

### 6.3 商机详情
返回 → 头部面板(客户与来源 / 商机名 / 优先级与标签 / 操作:新建跟进·编辑·更多)→ 阶段步进条(可点击推进)→ 关键信息六格(金额全额、赢率、预计成交、负责人、创建时间、最近活动)→ 左栏:待办跟进 + 跟进时间线;右栏:联系人(角色胶囊 + 最近联系)+ 关联想法(可转化)。输单商机顶部显示输单原因横幅。

### 6.4 联系人
表格:头像姓名 / 公司·职位 / 角色胶囊 / 电话 / 微信 / 关联商机 / 最近联系;超过 14 天未联系红色提示「N 天未联系」。

### 6.5 跟进项
分组面板:已逾期(红头)/ 今天 / 本周 / 以后 / 今日已完成(删除线,可撤销);组内按优先级→时间排序。完成跟进触发闭环 Toast(带「创建下一次跟进」按钮)。

### 6.6 统计
周期分段(本月/本季/今年/全部)→ 六项指标瓦片(新增/赢单/输单/赢单率/平均成交周期/平均客单价,缺数据显示「—」)→ 月度赢单趋势与在途阶段快照(双栏)→ 输单原因分布与来源分析表(双栏)→ 近 6 周跟进活跃度。图表规范:单序列单色(赢单 s5、活跃度 s3、输单原因中性灰),细柱 4px 圆角端、基线细分隔线、值标签用文字色、悬停原生提示、无图例(标题即序列名);趋势图固定近期区间,不随周期切换。

### 6.7 想法
顶部常驻速记输入框(回车即存,默认待评估)→ 卡片墙(auto-fill ≥310px):状态 + 优先级胶囊 / 标题 / 内容 / 关联与时间 / 操作(转为跟进项 · 升级为商机 · 搁置 · 重新激活)。

## 7. 响应式

| 断点 | 规则 |
| --- | --- |
| ≥ 921px | 桌面布局(侧边导航 + 双栏栅格) |
| ≤ 920px | 侧边导航折叠为顶部横向滚动条(隐藏角标与副题);所有双栏栅格降为单列;看板保持横向滚动;详情信息格 3 列 |
| ≤ 560px | 信息格 2 列;弹窗表单单列 |

## 8. 深色模式与可访问性

- 深色跟随系统(`prefers-color-scheme`),同时支持 `data-theme` 手动覆盖;组件一律通过 token 取色,禁止在组件内写死色值;
- 深色下优先级/阶段色整体提亮一档,保持在深底上的对比度;
- `:focus-visible` 品牌色描边;交互元素均为语义标签(button/a)并带 `aria-label`;
- `prefers-reduced-motion: reduce` 时关闭全部过渡与动画;
- 页面内横向宽内容(表格、看板)各自 `overflow-x: auto`,页面主体永不横向滚动。
